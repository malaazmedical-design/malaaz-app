# لوحة ملاذ — اختبار (مشروع malaaz-mizo-test فقط)

صفحة واحدة `index.html` بدون build. تشتغل على مشروع الاختبار فقط (مش التطبيق الأصلي).

## التشغيل
- محليًا: افتح `index.html` في المتصفح، أو انشرها على Vercel/Netlify (اسحب المجلد).
- الصلاحيات كلها عن طريق RLS: لازم يوزر الأدمن يكون في جدول `admin_users`.

## إنشاء أدمن (مرة واحدة)
1. Supabase → Authentication → Users → Add user (إيميل + باسورد) على مشروع `malaaz-mizo-test`.
2. شغّل في SQL Editor:
```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'ايميل-الأدمن@example.com';
```

## الموجود
- **أسئلة المرضى**: توجيه السؤال لتخصص (القائمة من الأطباء المفعّلين اللي بيقدموا استشارة أونلاين)، إلغاء، عرض المرفقات والرد.
- **مقدمو الخدمة**: تفعيل / إيقاف الحسابات الجديدة (بدل SQL اليدوي).
- **الاستشارات**: تأكيد الدفع (تم الدفع / في انتظار الدفع / إلغاء بسبب)، تنبيهات (انتهت المهلة، الطبيب لم يحدد موعدًا، العميل رفض، الطبيب متأخر)، استرداد، اعتماد التقييم.
- **الأسعار**: نطاقات أسعار الكشف والاستشارة حسب الدرجة.
- **التخصصات والمناطق**: إضافة/تعديل/إيقاف/حذف التخصصات والمحافظات والمدن والخدمات الفرعية (تمريض وأشعة). يحتاج تشغيل `22_admin_step6.sql`.
