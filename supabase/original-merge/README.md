⚠️ لا يتم تشغيل أي ملف هنا على الأصلي إلا بعد: (١) النسخة الاحتياطية، (٢) تجربته على نسخة، (٣) موافقة صريحة من المالك.

| الملف | الغرض | يغيّر سلوك التطبيق القديم؟ |
|---|---|---|
| `01_additive_safe.sql` | أعمدة اختيارية، جداول ودوال جديدة، سياسات إضافية، buckets جديدة | **لا** (مُختبر: صفر تغيير في ٣٣٦ كائن أصلي، وإعادة التشغيل آمنة) |
| `02_release_switch.sql` | توجيه الحجز بالمنطقة وتسعير القبول، صفوف الخدمات الجديدة، قفل سياسات «اسأل طبيب» القديمة، مهام cron | **نعم** — يُشغَّل وقت إصدار التطبيق الجديد |
| `03_security_hardening.sql` | قفل `Allow auth all` + قائمة ثغرات مفتوحة وخطوات تدوير السر | تقوية فقط |

  إشعارات الاستشارات و«اسأل طبيب» تعمل عبر `send_expo_push` الجديدة.
